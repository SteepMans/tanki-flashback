# Патчи Ruffle

56 патчей поверх апстрима [Ruffle](https://github.com/ruffle-rs/ruffle), без которых клиент в
браузере либо не работает, либо не играбелен. Сам Ruffle в репозиторий не вендорится: здесь только
диффы и закреплённый коммит, на который они накладываются.

## Апстрим

```
ruffle-rs/ruffle  7fb3d255eb3824507f52911b811fe75392218017
"tests: Add avm2/vector3d_near_equals test", 14.08.2026, workspace version 0.5.0
```

Патчи сделаны `git format-patch` и накладываются `git am` строго по порядку. На другой коммит
апстрима они, скорее всего, не наложатся: часть трогает `core/src/avm2/fast_paths.rs` и
рендерер Stage3D целиком.

## Что в них

| Патчи | Про что |
|---|---|
| 0001–0003 | `drawTriangles` с текстурами и uvt, перспективная коррекция подразбиением |
| 0002, 0010 | `Context3D.drawToBitmapData`, swizzle AGAL на коротких векторах |
| 0004, 0013 | `BitmapData.draw` масштабом на CPU для осе-выровненных преобразований |
| 0005–0006 | кеш пайплайнов и bind group, батчинг вызовов Stage3D в одну посылку за кадр |
| 0007, 0011 | слой Stage3D через «окно», вырезанное в интерфейсе (превью в гараже) |
| 0008, 0016 | повторная заливка пустых текстур, полная цепочка мипов |
| 0009, 0014, 0020, 0037, 0044, 0046 | статистика кадра и Stage3D в страницу: FPS, горячие методы, провалы |
| 0012 | коды клавиш по физической раскладке — иначе не работает управление не на латинице |
| 0017 | освобождение места в localStorage вместо падения `SharedObject.flush()` |
| 0018–0024, 0028, 0035–0036 | ускорение интерпретатора AVM2: слияние опкодов, инлайн-кеши, дешёвые проверки типов |
| 0026–0027, 0029–0034, 0039–0043, 0045, 0049–0056 | нативные реализации горячих мест игрового кода: отсечение сцены, матрицы, коллизии, BSP, сортировка, тени |
| 0041, 0048 | немедленная доставка в сокете и ожидание очереди WebSocket |
| 0047 | списание опоздавших кадров анимации |

Самое важное по эффекту: 0005–0006 (в бою было 15–20 кадров в секунду из-за посылки на каждую
модель) и серия нативных реализаций 0026+.

## Собрать

Скрипт `fetch-and-patch.sh` клонирует апстрим на закреплённый коммит и накладывает патчи:

```bash
./ruffle-patches/fetch-and-patch.sh        # создаёт ruffle-src/ рядом с репозиторием
```

Дальше по инструкции самого Ruffle (`ruffle-src/web/README.md`). Нужны:

- Rust stable и таргет `rustup target add wasm32-unknown-unknown`
- `cargo install wasm-bindgen-cli --version 0.2.120` — версия должна совпадать с той, что
  использует Ruffle, иначе сборка падает
- JDK (любой, годится headless) — для компилятора ActionScript
- Node 20+ и npm 7+
- `wasm-opt` из [Binaryen](https://github.com/WebAssembly/binaryen/releases) в `PATH`
  (опционально, уменьшает wasm)

```bash
cd ruffle-src/web
npm install
npm run build
```

Результат — `ruffle-src/web/packages/selfhosted/dist/`. Положить его целиком в
`server/webclient/ruffle-local/`:

```bash
cp -r ruffle-src/web/packages/selfhosted/dist/. server/webclient/ruffle-local/
```

Страница ждёт там `ruffle.js`, `core.ruffle.<hash>.js`, `<hash>.wasm` и `package.json`. Сборка
занимает порядка получаса на холодном кеше и весит около 14 МБ, поэтому в репозиторий она не
попадает (`server/webclient/ruffle-local/` в `.gitignore`).

Проверить, что подхватилось: открыть `http://localhost:9999/web/` и посмотреть в счётчик поверх
игры (F8 прячет). Без патчей `drawTriangles` танк будет без текстур.

## Другие сборки Ruffle

Страница умеет переключаться, чтобы отделять баги игры от баг эмулятора:

- `?ruffle=stable` — релиз 0.5.0 из `server/webclient/ruffle/`
- `?ruffle=nightly` — сборка апстрима из `server/webclient/ruffle-nightly/`
- без параметра — наша из `ruffle-local/`

Обе чужие сборки скачиваются с [релизов Ruffle](https://github.com/ruffle-rs/ruffle/releases) и в
репозиторий тоже не входят.
